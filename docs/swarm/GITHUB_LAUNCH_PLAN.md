## Release promise

**Alpha user story:** supply a two-task plan, select one supported model, run two
workers concurrently through AO, then inspect their frozen changes and execution
records. Human review/integration; source working files must remain unchanged.

One tested Mac setup, one existing authenticated provider, clean committed input,
two independent assignments, AO worktrees/session lifecycle, supplied planner
JSON. No new planner-model integration, executor, database, dashboard, automatic
merge, token predictor or multi-provider support is needed for this release.

**Developer preview can publish first:** tested coordination source plus a
reproducible offline example, explicitly saying live Praxis execution is pending.
Only advertise a working supervised swarm after the connected live demo passes.

## Execution contract

- AO owns live sessions/worktrees. Use a clearly named supervised-AO integration
  profile; our exact-copy scheduler remains disabled for live execution until its
  stronger requirements pass. Do not remove its gate or label test receipts live.
- Capture the actual AO workspace/configuration after preparation. Do not invent
  an exact-copy binding or claim that the existing receipt bridge was exercised.
  Reuse existing storage; no competing scheduler or experimental-board cutover.
- Keep ordinary cleanup away from the user's source and retain candidate
  artifacts before teardown. Unknown process state stays unknown; no automatic
  replacement launch, retry or capacity release based on uncertainty.
- Native worktrees are not an adversarial sandbox. Describe inherited permissions
  and cancellation limits accurately. Container containment stays on the full
  roadmap unless the selected minimal workflow actually requires it.
- Run two initial worker sessions with recorded wall-time limits. Existing
  authentication only; no provider substitution, new billing route or silent
  permission bypass. A blocking setup/model issue gets one bounded diagnosis;
  any further model run is an explicit new decision, not an automatic retry.
