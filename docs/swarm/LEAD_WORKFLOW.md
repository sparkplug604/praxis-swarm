# Start your first Praxis Swarm project

Watch an AI lead turn a small project goal into a plan, delegate to two workers,
and test the combined result. Start with a disposable Python project so you can
see the complete workflow before connecting your own code.

Choose how you want to begin:

- **[Use Codex with natural language](GET_STARTED_CODEX.md)** — paste a request;
  Codex handles the local setup and starts your managed AI lead.
- **[Use the terminal](GET_STARTED_TERMINAL.md)** — run the setup commands yourself,
  then hand planning, delegation and review to the lead.

Both paths use the same workflow: **Sol/high lead → two Luna/low workers → lead
review**. They use your existing Codex login and consume model usage. The tested
setup is macOS with Bash, Git, Python 3 and Go 1.27.1; no desktop build is needed.
The lead creates the worker plan; you do not write a plan JSON file.

To shape an incomplete goal, use [Project Discovery](PROJECT_DISCOVERY.md).
The managed lead saves questions and decisions, then binds planning to the ready brief.

After the first run, see [using your own project](GET_STARTED_CODEX.md#use-your-own-project).
For proposal fields, native tools, permissions, API operations and recovery, use
the [technical reference](LEAD_REFERENCE.md). To supply an existing plan yourself,
use the [supervised CLI reference](SUPERVISED_WORKFLOW.md).
